# 雙北軟體求職雷達

GitHub Pages 靜態網站。`index.html` 為進入點。

## V2 更新

- 移除固定 SWOT，新增多選技能、自訂技能、公司搜尋與技術覆蓋分析。
- 使用者技能僅保存在瀏覽器 localStorage，不會傳回伺服器。
- 公司技術需求是依產業類別與既有業務文字建立的**示範假設**，不是經查證的職缺要求。
- 200 家資料仍為初評候選，部分地點待核實。

## 部署

將 `index.html` 與本檔放到 GitHub repo 的 `main` 分支根目錄，於 Settings → Pages 選 Deploy from a branch → main / (root)。
